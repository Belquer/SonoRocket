# SonoRocket: como usar

Serve para o dB ouvir a mix direto do seu Pro Tools, com qualidade máxima, pelo celular ou computador dele.

## Primeira vez (5 minutos)

1. Abra o arquivo **SonoRocket-mac.zip** que o dB mandou. Vai aparecer o **SonoRocket.app**. Arraste-o para a pasta **Aplicativos**.
2. Dê dois cliques no **SonoRocket.app**.
   - Se o Mac disser que não pode abrir: abra **Ajustes do Sistema → Privacidade e Segurança**, role até o fim e clique em **Abrir Mesmo Assim**. Isso só acontece uma vez.
3. Aparece o aviso **"Plugin SonoRocket instalado ✓"**. Clique em **Entendi**.
4. No Pro Tools, no **Master Fader**, no último insert, coloque o **Blue Cat PatchWork**. Dentro dele, escolha **SonoRocket**. Salve a sessão.

## Toda vez que for mostrar a mix

1. Dois cliques no **SonoRocket.app**.
2. Espere a janelinha com o link (uns 10 segundos).
3. Clique em **Mandar no WhatsApp** e escolha o dB.
4. Dê play no Pro Tools. Pronto.

Deixe a janelinha aberta enquanto ele estiver ouvindo. Para encerrar, clique em **Desligar**.

## Se algo não funcionar

- **A janela diz "Esperando o Pro Tools":** confira se o SonoRocket está no Master, dentro do PatchWork.
- **No plugin aparece "Abra o app SonoRocket":** abra o app. O plugin conecta sozinho.
- **Não aparece o link:** confira se o Mac está na internet e clique em **Tentar de novo**.

O som sai do Pro Tools exatamente como está no Master, sem compressão. O dB escuta uns 2 segundos atrasado, e isso é normal. Para comentar, use a minutagem (por exemplo, "no 2:14").
